Controls

WASD - Movement
Space - Jump
L-Click - Place/Destroy
R-Click - Edit Mode
M-Click - Pick Block
1-9 - Select Block
Y - Invert Y-axis
T - Open Chat
Esc - Pause/Menu
R - Respawn
F - Toggle Fog
G - Spawn Mob
TAB - Player List
B - Build Menu
M - Toggle Sounds
